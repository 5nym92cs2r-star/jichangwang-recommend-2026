- **线路**：括号里是信息来源。「官方称」「官网首页称」「套餐说明称」摘自商家说明；「站长提供」来自站长（站长与名单品牌有推广关系），不是商家说明。都未经机场网核实，机场网没有购买或测速，线路类型不代表实际速度。
- **官方优惠码**：摘自各家官方面板公告，有适用条件（新客或老用户、限周期、限量、截止日期等）。表中价格没有扣除优惠，条件见品牌页，以结算页为准。
